# Contributing

We welcome contributors! For your pull requests, please include the following:

- A sample file/code snippet that reproducibly causes the bug or issue you're fixing.
- Documented code providing the fix — please include a docstring for any new function or
  class.
- Unit tests evaluating any added or modified methods (see [docs/testing.md](docs/testing.md)
  for how to run the suite).

For questions or problems, please open an issue on the repository, including code/files that
reproduce the problem where possible.
